# Security policy

Please report security problems privately, not in a public issue, discussion or pull request.

Report them through GitHub private vulnerability reporting:
https://github.com/revjmoney/ardustep/security/advisories/new

Include what the problem is, how to reproduce it, and the version or commit you tested.
Only the maintainer sees the report. Fixes go to the latest version on `main`.
